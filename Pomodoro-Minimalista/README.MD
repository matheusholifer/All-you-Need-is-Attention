Este projeto é um simulador de Pomodoro minimalista desenvolvido como parte de uma série de programas voltados ao foco, disciplina e melhoria da atenção. A aplicação permite ao usuário escolher entre ciclos de estudo de 25 ou 50 minutos, seguidos automaticamente por períodos de descanso proporcionais, criando um fluxo contínuo e eficiente de produtividade. Ao final de cada ciclo, um alerta sonoro é emitido, e o sistema conduz o usuário para a próxima etapa, mantendo o ritmo de trabalho. O projeto inclui ainda funcionalidades como avanço rápido para os segundos finais e um contador de tempo total estudado durante a sessão. Desenvolvido dentro do conceito de “vibe coding”, o projeto prioriza simplicidade, fluidez e experiência do usuário. Para sua construção, foi utilizado o ChatGPT como apoio no desenvolvimento e estruturação do código.
