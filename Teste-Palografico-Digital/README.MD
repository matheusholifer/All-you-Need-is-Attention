O Teste Palográfico Digital simula o controle de tempo utilizado no teste palográfico aplicado em avaliações psicológicas, como as do DETRAN. O objetivo é auxiliar no treinamento do ritmo de execução dos traços, fornecendo sinais sonoros e visuais em intervalos regulares de 1 minuto. Nos momentos de “sinal”, o jogador deve realizar o traço horizontal em sua folha e continuar o exercício normalmente.
Este projeto foi desenvolvido com foco em uma interface minimalista e funcional, sendo necessário que o usuário possua uma folha física do teste palográfico para realizar a atividade corretamente.

Trata-se de um projeto de vibe coding, desenvolvido com apoio de inteligência artificial, incluindo o uso do Gemini, com o objetivo de aprendizado e experimentação.
