Teste de Atenção Visual é uma aplicação interativa desenvolvida com o objetivo de simular exercícios de foco e tempo de reação, semelhantes aos utilizados em avaliações psicotécnicas, como as do DETRAN. O usuário deve identificar rapidamente se o símbolo exibido corresponde aos alvos definidos, treinando atenção, agilidade mental e tomada de decisão.
Este projeto foi desenvolvido com a proposta de vibe coding, priorizando aprendizado prático, experimentação e evolução contínua durante o desenvolvimento. Para apoio na construção e refinamento do código, também foi utilizada a ferramenta Gemini.

Os ícones utilizados na interface foram obtidos a partir da biblioteca Devicon, disponível em: https://devicon.dev/
