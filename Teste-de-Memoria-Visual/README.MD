Teste de Memória Visual é uma aplicação interativa desenvolvida com o objetivo de simular exercícios de memorização e reconhecimento, semelhantes aos utilizados em avaliações cognitivas. O usuário deve analisar e memorizar símbolos e palavras durante um período limitado, e posteriormente identificar quais elementos estavam presentes, diferenciando-os de itens impostores.
Este projeto foi desenvolvido com a proposta de vibe coding, priorizando aprendizado prático, experimentação e evolução contínua durante o desenvolvimento. Para apoio na construção e refinamento do código, também foi utilizada a ferramenta Gemini.

Os ícones utilizados na interface foram obtidos a partir da biblioteca Devicon, disponível em: https://devicon.dev/
